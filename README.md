# CodeX Token Documentation

This repository contains the documentation for the CodeX (CDX) token project. It is maintained by Coded House LLC.

The purpose of this repo is to keep public-facing documents in one place — things like the whitepaper, audit reports, reserve attestation records, and technical verification materials. It is not a code repository. Smart contract source code lives in a separate repo.

## What's in here

The docs are organized by type. As new documents get published, they get added here.

- **Whitepaper** – the main technical and informational document describing the protocol.
- **Audit reports** – security reviews from independent firms.
- **Reserve attestation** – reserve verification records and supporting evidence.
- **Legal and entity documents** – certificates, registrations, and compliance filings.
- **Technical verification records** – hashes, manifests, and on-chain evidence references.

## Document status

Documents in this repository are published as-is at the time of upload. They are point-in-time records, not live guarantees. The latest on-chain state should always be checked directly against the contracts before relying on any figure or claim.

## How to use these docs

If you're an institutional counterparty, auditor, or regulator reviewing the project, start with the whitepaper. Then go through the audit reports and reserve attestation records. All documents are meant to be read together — no single document tells the full story.

If you're a developer or technical reviewer, the source code repo is the place to look for implementation details. This repo is for the documents that support the project, not the code itself.
